JD RETAILER - SUBSCRIPTION FIRST + OWNER ACCESS CODE

FINAL ACTIVATION FLOW
1. Customer installs JD Retailer.
2. Customer enters mobile number.
3. App immediately shows ₹50/month subscription screen.
4. Customer completes Google Play subscription payment.
5. After successful subscription, app shows "Enter Owner Access Code".
6. Customer contacts you / JD Retailer owner for access.
7. You generate an access code for that customer's mobile number.
8. Customer enters the code.
9. Only when BOTH are valid:
   - active ₹50/month subscription
   - valid Owner Access Code
   the billing app opens.

IF SUBSCRIPTION EXPIRES
- App locks and returns to ₹50/month subscription screen.

IF OWNER ACCESS EXPIRES
- Subscription may remain active, but app still locks and asks for a new Owner Access Code.

OWNER ACCESS GENERATOR
Use JD_Retailer_Owner_Access_Generator.html privately.
Do not share that admin generator with customers.

IMPORTANT PAYMENT NOTE
For Play Store distribution, digital subscription payment is handled by Google Play Billing.
Your UPI is not used directly as the unlock mechanism in this Play Store build.

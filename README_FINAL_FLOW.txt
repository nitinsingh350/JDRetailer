JD RETAILER - ACCESS CODE ONLY FINAL FLOW

CUSTOMER FLOW
1. Customer opens JD Retailer.
2. First screen shows:
   - Premium Access
   - ₹50/month
   - Get Access / Activate
3. Customer taps Get Access / Activate.
4. App asks for:
   - 10-digit mobile number
   - Owner Access Code
5. Customer pays you separately as agreed.
6. You generate an Access Code using JD_Retailer_Owner_Access_Generator.html.
7. You send the code to the customer.
8. Customer enters the code.
9. If the code is valid and matches that mobile number, JD Retailer unlocks completely.
10. Until a valid code is entered, the app stays locked.

ACCESS CODE
- Generated by your existing private Owner Access Generator.
- Can expire after the validity you choose.
- Is tied to the customer's mobile number.
- No Google Play Billing is required in this build.

IMPORTANT
The app displays ₹50/month as your access price, but payment confirmation itself is manual/offline.
You decide whether to give the access code after receiving payment.
